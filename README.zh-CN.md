# 舟入千里

[English](README.md) · **简体中文**

以王希孟《千里江山图》为原景的交互式山水漫游：一幅长卷、一叶小舟，留一点时间，慢慢看画。

**[中文版在线体验](https://qianli-boat-journey.rainatwu.chatgpt.site/)** · **[英文版在线体验](https://qianli-boat-journey.rainatwu.chatgpt.site/en/)**

网站公开访问，无需登录。以上链接可以直接体验完整网站。在线网站与 GitHub 仓库独立发布，向仓库提交代码不会自动更新在线版本。

## 核心体验

原画本身已经足够美。这个项目用克制的动画与批注，让用户在欣赏原画的过程中，感受“人在画中游”。

1. **开卷入画。** 向下滚动或点击入画按钮，首页标题向右滑动、淡出，画卷随之展开。
2. **滚动展卷。** 用纵向滚动控制长卷，从右向左游览；反向滚动可以回看经过的山水。
3. **驻足发现。** 十二个停留点结合六处山水视点，以及过桥、靠泊、野渡、寻渔、水磨、听瀑等互动。到达景点时，镜头缓缓放大、展开批注；继续滚动即可前行。
4. **自由细看。** 点击画面未标注的位置，打开局部缩放菜单。进入细看模式后可以自由拖动和缩放；缩小到全景尺度后，重新衔接展卷浏览。
5. **寻找小舟的来处。** 点击行舟获得线索，再在原画中找到对应的小舟，解锁寻舟彩蛋。

开头题诗可以按需展开阅读，已去掉语音朗读。英文版保留原中文题诗，并附有明确标注的英文阅读提示。可选的合成流水环境音默认关闭。

## 为什么采用这些技术

网站使用 **HTML、CSS 和原生 JavaScript**，以静态文件形式运行，无需应用服务器、数据库或安装前端依赖。

| 技术选择 | 对体验的帮助 | 当前取舍 |
| --- | --- | --- |
| 按当前视野加载 20 张 JPEG 图块 | 先显示低清全卷，再优先加载当前视野和邻近高清细节，同时最多发起两项请求；失败可以重试，不阻塞入画。 | 尚未采用多分辨率金字塔。已离开视野的高清图片会按约六张的常驻预算移除；当前及邻近图块可能超过此预算。浏览器缓存与解码内存回收仍由浏览器管理。 |
| 将原生页面滚动映射到镜头时间线 | 用熟悉的滚动动作串联行进、放大、停留和缩小，反向滚动也能自然回看。 | 滚动距离经过编排，并非与画卷横向位移一比一对应。 |
| CSS transform 与 `requestAnimationFrame` | 统一变换画面场景，保持原画细节和交互位置对齐；直接操作可以接管镜头过渡。 | 流畅度仍受图像解码、设备内存和浏览器性能影响，不保证固定帧率。 |
| Pointer Events 与触摸处理 | 鼠标拖动和双指缩放使用同一套镜头模型，通过位移阈值区分点击与拖动。 | 仍需在真实触摸设备上进行跨浏览器验证，模拟手机尺寸不能替代真机测试。 |
| 原生 HTML 按钮和对话框 | 控件具有文字标签，支持键盘操作，也便于检查和维护。 | 长卷本身仍是视觉内容，尚未提供完整的非视觉导览。 |
| CSS 响应式布局与减少动态效果支持 | 手机使用紧凑控件和底部批注；系统请求减少动态效果时，会减少定时动画。 | 滚动驱动的空间移动仍是核心体验的一部分。 |
| Web Audio API | 在本地合成轻柔流水声，无需外部音频服务或流媒体配乐。 | 声音属于艺术化处理，并非实地录音。 |
| `localStorage` | 将发现进度保存在用户浏览器中，无需账号和后端。 | 清除浏览器存储会重置进度，进度也不会跨设备同步。 |
| 自动生成英文入口 | 从共用的交互源码生成英文文件，两种语言共享素材，无需运行时翻译库，可部署在静态托管平台。 | 修改共用文案或交互后需要重新生成英文版；切换语言会回到入口。 |

这套技术的优势在于与项目需求匹配：围绕静态长卷组织镜头、时间线和交互点，代码结构直接，也方便独立部署和维护。

## 本地运行

在仓库根目录运行以下命令，需要 Python 3，无需安装依赖：

```sh
python -m http.server 8000 --directory dist
```

打开[中文版](http://localhost:8000/)或[英文版](http://localhost:8000/en/)。请通过本地 HTTP 服务访问，不要直接双击 HTML 文件。

修改中文源码、交互逻辑或 `translations-en.txt` 翻译表后，重新生成英文版并检查脚本语法：

```sh
python scripts/build-english.py
node --test tests/image-loader.test.cjs tests/journey.test.cjs
node --check dist/app.js
node --check dist/en/app.js
node --check dist/en/painting-menu.js
node --check dist/en/boat-egg.js
```

Python 和 Node 仅用于本地开发及检查，线上静态网站不依赖它们运行。生成器发现英文 JavaScript 中仍有中文时会报错；英文 HTML 中的中文题诗和印章则是有意保留的内容。

```text

  index.html           中文入口及页面结构
  app.js               滚动时间线、镜头、小舟路线和场景

  assets/              原画、图块、局部细节和小舟素材
scripts/
  build-english.py      英文版生成脚本
translations-en.txt    英文翻译表
```

部署时将 `dist/` 中的内容上传到静态托管平台，保留 `en/` 与 `assets/` 的目录关系。英文页面通过相对基础路径共享素材，避免重复存放图片。公开仓库不包含托管凭据、部署元数据、本地研究文件及文档预览以外的开发截图。

## 原画来源与创作说明

- 原作：北宋王希孟《千里江山图》，1113 年，故宫博物院藏。
- 图像来源：[Wikimedia Commons 完整长卷（标注为公有领域的版本）](https://commons.wikimedia.org/wiki/File:Wang_Ximeng._A_Thousand_Li_of_Rivers_and_Mountains._(Complete,_51,3x1191,5_cm)._1113._Palace_museum,_Beijing.jpg)。
- 数字图像尺寸：**39,974 × 1,600 像素**，包含装裱、题跋和印章。
- 馆藏介绍：[故宫博物院](https://www.dpm.org.cn/collection/paint/228354.html)。
- 卷首后加题诗：[故宫博物院释文](https://www.dpm.org.cn/subject_rivsmounts/qljs/245996.html)，为乾隆时期所加，晚于原画数百年。

山水画面保持原图。移动的小舟是**以原画长桥旁的小舟为参照，经 AI 辅助提取与重建的素材**，并非逐像素一致的档案级抠图。行舟路线、流水声、水磨示意和互动故事属于当代演绎，不能作为历史运动方式或工程结构的精确复原。相关批注附有来源链接。

## 已验证范围与当前限制

- 已在浏览器检查入画、滚动、批注、自由探索、缩放菜单位置、题诗弹窗和寻舟彩蛋。
- 响应式检查覆盖小尺寸竖屏、常规竖屏和较矮横屏；真实设备上的多点触控仍需进一步验证。
- 入画不再等待全部 20 张图块。390 × 844 竖屏检查中，初始视野仅请求第 17–19 号图块，其下始终保留低清全卷；较宽视野可能请求更多图块。这是请求范围检查，不是移动网络耗时基准测试。
- 已通过 21 项无第三方依赖的 Node 测试，覆盖图片请求优先级／并发／重试／释放、中英文入画、景点批注、点击与拖动、双指状态、缩至全景衔接展卷、尺寸变化、键盘入口和彩蛋记录。交互测试在轻量 DOM 适配器中执行实际脚本，不模拟真实浏览器渲染或原生触摸。
- 浏览器检查覆盖 390 × 844 中文竖屏、320 × 568 英文竖屏及 844 × 390 横屏。竖屏底部主要按钮点击区域为 44 px，批注位于底栏上方，未发现页面横向溢出。真实设备上的双指与滚动手势仍待验证。
- 持续运行的动画循环与全分辨率图像解码会占用设备资源，低内存设备仍可能吃力；技术栈简单不等于已经通过性能基准测试。
- 应用代码不包含访问分析、账号系统或服务端进度存储。

### 手机触摸展卷

在画面上左滑前进、右滑回看。到达景点后自动完成约 800 毫秒的镜头过渡，同一次手势不会跳过景点；动画结束后松手再次左滑即可继续，右滑可回看。批注独立滚动。点击画面进入自由细看后，单指拖动、双指缩放。桌面滚轮仍按滚动进度展卷。新增五项状态回归测试覆盖到站、动画中重复输入、反向回看、手势取消、纯画模式和桌面行为；真实 iOS/Android 触摸验证仍待完成。
